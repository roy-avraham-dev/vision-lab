# מעבדת הראייה — קורס ראייה ממוחשבת

אתר לימוד מקומי בתשעה מודולים (0–8), מהבסיס ועד פרויקט גמר: מעקב אחרי רכבים בצילום רחפן ומדידת המהירות שלהם בקמ"ש, מתוך הסרטון בלבד.

## פתיחת האתר
פותחים את `index.html` בדפדפן. אין צורך בהתקנה.

## האפליקציה של הפרויקט (מודול 8)
הקבצים נמצאים ב־`assets/files/m8_app/`.

```
pip install PySide6 opencv-python numpy ultralytics
python assets/files/m8_app/app.py
```

החלון נפתח במסך מלא. בוחרים סרטון, לוחצים "התחל סריקה", ומקבלים סרטון מסומן לצד טבלה חיה.

## הערות
- משקלי המודל (`yolo11m.pt`) לא נשמרים במאגר; הם יורדים אוטומטית בהרצה הראשונה.
- `_claude/` — הנחיות וכלי בנייה להמשך פיתוח האתר.
